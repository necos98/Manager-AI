Service classes (IssueService, ProjectService, etc.) are instantiated per-request — one AsyncSession → one service instance. Instance attributes (dict, etc.) therefore live exactly for the request lifetime and need no TTL, invalidation, or cleanup.

**Pattern:** `self._cache: dict[str, X] = {}` in `__init__`, checked before any repeatable expensive call within the same request.

**First use:** `IssueService._path_cache` caches `project_id → path` to avoid duplicate `ProjectService.get_by_id()` SQL queries when multiple methods resolve the same project_id.

**Rule:** When a service method calls the same expensive lookup multiple times within a request, cache the result on `self`. No contextvars needed — the instance is the scope.
