_load_project_into_memory uses local imports inside the function body (e.g. `from app.storage.memory_store import MemoryRecord, MemoryLinkRecord`) to avoid circular imports with app.routers.projects and app.storage modules. The extracted storage/project_loader.py must preserve this import pattern or use a lazy import approach.
