Agent, Pipeline, PipelineStep are SQLAlchemy ORM models in the SQLite database. Unlike Issue (which is file-backed via app.storage.issue_store), these have no file storage layer. Services follow the CredentialService pattern: AsyncSession per instance, SQLAlchemy queries with flush() on mutations, commit() in routers. Use select() + scalar_one_or_none(), self.session.add(), self.session.delete().
