User explicitly chose "Catalog only" — removed manual "Add Plugin" free-form dialog entirely. All plugins must be in the catalog (`backend/plugins/<key>/plugin.yaml`). PUT /api/projects/{id}/plugins/{key} rejects keys not in catalog with 400 error. Legacy v1 plugins (pre-catalog) shown as read-only in UI — can be disabled/deleted but not edited. No new non-catalog plugins can be created.

Why: User stated "Catalog only" during design phase (2026-05-14). Cleaner UX, no confusion between catalog and manual plugins. No escape hatch needed — if a plugin isn't in catalog, developers add it via PR.
