Adding a field to issue data requires touching ALL of these in `backend/app/storage/issue_store.py`:
- `IssueRecord` dataclass
- `_to_index_entry()` — in-memory index
- `_index_to_light_record()` — light record from index
- `_record_to_payload()` — to disk queue
- `_write_issue_record()` — YAML payload on disk
- `rebuild_issues_index()` — index rebuild
- `load_issue()` — disk fallback

Plus: Issue model, IssueCreate/Update/Response schemas, `IssueResponse.from_record()`, service create/update_fields, router. Missing any layer = silent data loss because the system is RAM-first with async disk writes via WriteQueue.
