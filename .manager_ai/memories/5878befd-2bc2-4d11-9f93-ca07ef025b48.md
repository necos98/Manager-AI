Adding new file type support requires touching three places:
1. file_reader.py: add extraction function + wire into extract() dispatcher + add to AUDIO_EXTENSIONS or equivalent set
2. file_service.py: add extension to ALLOWED_EXTENSIONS, add MIME type to MIME_MAP, decide sync/async/pending in upload_files()
3. tests/test_file_reader.py: add dispatcher routing test + missing-dependency test

Extraction status values: pending (async processing), ok (done), failed (error), skipped (images), unsupported (legacy/doc/xls).
