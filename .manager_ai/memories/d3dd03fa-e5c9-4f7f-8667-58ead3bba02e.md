The implementation plan called for wrapping the asyncio exception handler in configure_error_logging() to chain logging before the Windows accept noise suppressor. This was NOT done because: the wrapper would log suppressed Windows noise errors (WinError 64/121/995/1236) as ERROR-level files before the suppressor could filter them, creating spurious log files. Instead, AC1 is satisfied by sys.excepthook + ErrorFileHandler auto-capture of all logger.exception() calls throughout the codebase — no asyncio wrapping needed.
