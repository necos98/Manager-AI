`Project.shell` (DB field, settable via API + MANAGER_AI_SHELL env var) flows into `pty.spawn()` with zero input validation at terminal_service.py:138 (WSL) and :140 (non-WSL). Embedded quotes, backticks, $(), ;, |, &, \\n enable command injection. Fix requires 3 layers: pydantic validator on shell schema field, validation at spawn site in terminal_service.py, and resolving wsl.exe via shutil.which() for WSL path.
