When spawning a background task (asyncio.create_task) that opens its own DB session via session_factory, the calling method must commit() — not just flush() — before the create_task call. Otherwise the background task's new session can't see uncommitted records (NotFoundError). Pattern found in PipelineRunService.start() at pipeline_run_service.py:99. Fix: add await self.session.commit() before create_task.
