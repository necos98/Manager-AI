Project is configured for Claude Code worktrees:

1. **`.gitignore`** ignores `.claude/worktrees/` (Claude Code default worktree location) — prevents worktree dirs appearing as untracked files
2. **`.worktreeinclude`** copies `.env` into new worktrees — worktrees are fresh checkouts without gitignored files, `.env` is needed for DB connection and runtime config

**Why `worktree.baseRef` stays default `"fresh"`**: branches from `origin/HEAD` giving clean starting tree. `"head"` would carry unpushed commits, undesirable for agent worktrees.

**How to apply:** When adding new gitignored config files that worktrees need at runtime, add them to `.worktreeinclude`. Build artifacts (`node_modules/`, `.venv/`, `data/`) should NOT be added — they need fresh install per worktree.
