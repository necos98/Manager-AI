pywebview does not expose an icon parameter in create_window(). On Windows, set the window icon via ctypes Win32 API: FindWindowW → LoadImageW → SendMessageW(WM_SETICON). This must happen AFTER webview.start() creates the native window — calling it after create_window() (before start) fails because the HWND doesn't exist yet. The poll_worker callback (passed as func= to webview.start) runs after native window creation, so set the icon there on the first iteration.

Module: backend/app/desktop_icon.py — set_app_window_icon(window_title, ico_path)
Icon file: logo.ico (auto-generated from logo.png by _ensure_app_icon() in start.py)
Conversion: PIL/Pillow, 4 sizes (16, 32, 48, 256 px)
Windows only (ctypes.windll), fallback silent on error.

Why: User wanted custom app logo instead of default Python icon in taskbar/title bar. ctypes chosen over pywin32 to avoid extra dependency.
