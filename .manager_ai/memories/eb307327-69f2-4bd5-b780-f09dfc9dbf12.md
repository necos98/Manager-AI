The `get_active_agent(issue_id)` MCP tool (in server.py ~L1105-1125) is the SINGLE source of truth for pipeline agent identity via MCP. It returns `{run_id, step_run_id, agent_name, agent_intent, step_index, step_status, terminal_id}`. Returns `{active: null}` when no pipeline is running.

Previously, agent identity was also available through env vars (MANAGER_AI_AGENT_NAME, MANAGER_AI_AGENT_ROLE, MANAGER_AI_AGENT_INTENT) set in the PTY subprocess — these were removed (issue e3dc18ff) to eliminate dual-source confusion. The Claude Code MCP client cannot read env vars from the terminal session anyway.

This tool queries `PipelineRunService.get_runs_for_issue()` to find the active RUNNING pipeline run and returns the current step's details.
