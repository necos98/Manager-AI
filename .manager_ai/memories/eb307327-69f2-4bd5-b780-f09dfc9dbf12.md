The `get_active_agent(issue_id)` MCP tool (in server.py ~L1105-1123) lets pipeline agents discover their identity via MCP. Previously, agent identity was only available through env vars (`MANAGER_AI_AGENT_NAME`, `MANAGER_AI_AGENT_ROLE`) set in the PTY subprocess — but the Claude Code MCP client cannot read env vars from the terminal session. This tool queries `PipelineRunService.get_runs_for_issue()` to find the active RUNNING pipeline run and returns the current step's `{agent_name, step_index, step_status, terminal_id}`. Returns `{active: null}` when no pipeline is running.
