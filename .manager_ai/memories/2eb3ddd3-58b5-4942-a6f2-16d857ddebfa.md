read_env() and write_env() in CredentialEditorService use static file helpers (no DB session needed). The router creates a bare instance via SVC.__new__(SVC) for these endpoints to avoid depending on get_db. Preset CRUD endpoints need the DB session. This is intentional — reading/writing ~/.claude/credentials.json is pure filesystem work.
