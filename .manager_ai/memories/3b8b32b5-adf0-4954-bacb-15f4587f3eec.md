Calling `_response(agent)` AFTER `await db.commit()` triggers MissingGreenlet because async SQLAlchemy expires all ORM attributes on commit. Sync access to expired attrs tries lazy-load outside async context. Fix: capture response data into a variable BEFORE commit, then commit, then return the captured variable. Found in agents.py: create_agent, update_agent, seed_agents. Also spotted in issue_relations.py and project_links.py (not fixed — separate issue).
