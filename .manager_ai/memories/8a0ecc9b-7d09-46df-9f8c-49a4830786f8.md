Bug: PipelineRunService.start() uses flush() not commit() before spawning _execute() as background task via asyncio.create_task. _execute() opens new session via session_factory() which can't see uncommitted records → NotFoundError. 

Fix: Add await self.session.commit() at pipeline_run_service.py:98, between step-run creation loop and create_task call.

Why tests miss: Tests construct PipelineRunService(db_session) without session_factory, so _execute() reuses same session where flushed data IS visible.

Rule of thumb: Any method that creates records and spawns a background task reading those records must commit() first, not just flush().
