PipelineRunService._execute() finally block was missing _stop_reader() and _sessions.pop() after kill(). This leaked TerminalSession objects (reader tasks, pty_dead Events) in module-level _sessions dict per pipeline step. Any new code that creates TerminalSessions must follow the full cleanup sequence from terminal_session module: save_recording → stop_reader → pop → kill. The delete_terminal endpoint and _teardown_terminal helper in terminals.py are the canonical patterns.
