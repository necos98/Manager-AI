Plugin connection errors use `logger.error()` for console output (clean, no stack trace) + `logger.debug(exc_info=True)` for diagnostics. Pattern applied in `plugin_client.py` (4 locations) and `plugin_manager.py` (1 location). 

Why: User complained about full Python stack traces in console when MySQL plugin fails to connect. Console should show only "Plugin mysql connect failed". Full traceback still available at `LOG_LEVEL=DEBUG`.
