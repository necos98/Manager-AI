Feature: "Create issue from here" button on issue detail page. Opens NewIssueDialog, auto-creates "related" relation between source and new issue. Recommended approach: add optional `source_issue_id` to IssueCreate schema so backend IssueService.create() delegates to IssueRelationService.add_relation() after creation — single API call, atomic, no orphan risk. Button goes in IssueActions bar, visible even in terminal states (Finished/Canceled). Frontend: NewIssueDialog gets optional sourceIssueId prop; on submit passes source_issue_id to backend. `NewIssueDialog` currently only exists on issues list page — needs to be importable from issue detail page too.
