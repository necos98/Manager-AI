The health endpoint `GET /api/projects/{project_id}/health` includes a `resource_consistency` check that scans all `.manager_ai/` YAML files for `project_id` mismatches and auto-fixes them without requiring a flag or user confirmation.

**What it scans:**
- `issues.yaml` index entries
- `.manager_ai/issues/<id>/issue.yaml` individual files
- `memories.yaml` index entries
- `.manager_ai/memories/<id>.md` YAML frontmatter

**Key decisions:**
- Auto-fix always (no opt-in flag) — user explicitly chose this behavior
- All resource types scanned, not just index files — user explicitly chose full coverage
- Missing directories/files skipped silently (not errors)
- Atomic writes via `tmp + os.replace()` pattern from `storage/atomic.py`
- Memory .md frontmatter parsed via `split("---", 2)` to preserve body content exactly
- Function lives in `backend/app/routers/projects.py` alongside `_check_manager_json`, `_check_claude_resources`, `_check_mcp`

**Why:** Before the "Flat System" refactor, two users on the same project could overwrite `manager.json` with different project_ids, breaking MCP routing. This health check prevents that class of bug.
