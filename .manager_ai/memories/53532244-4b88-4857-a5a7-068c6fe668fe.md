When filtering collections by optional string params defaulting to None, use `if x is not None` not `if x`. Empty string "" is falsy in Python — truthiness check treats it as "no filter," returning all items instead of only empty-string ones. Bug hit in `TerminalService.list_active(project_id="")` which returned ALL terminals instead of only manage-agent ones (project_id="").
