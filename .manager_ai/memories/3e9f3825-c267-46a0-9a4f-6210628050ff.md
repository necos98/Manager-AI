`PipelineService.seed_defaults()` and `AgentService.seed_defaults()` are idempotent — they only create defaults if the project has 0 agents/pipelines. After changing `DEFAULT_AGENTS` values (e.g., `terminal_command`, `system_prompt`), existing pipelines still have the OLD values baked into their `PipelineStep` rows.

To apply DEFAULT_AGENTS changes to an existing project: delete the default pipeline via UI or API, then restart the backend. The startup seed in `main.py` will recreate agents and pipeline with the new values.

**Why:** Idempotent seed prevents duplicate agents/pipelines on every restart. The cost is that updates to DEFAULT_AGENTS don't propagate automatically.

**How to apply:** Document this step whenever DEFAULT_AGENTS changes. Alternative: manually update each PipelineStep's `terminal_command` via the API/frontend without deleting the pipeline.
