PluginManager._start_one is called from both start_plugins_for_project (which sets self._state[project_id] first) and enable_plugin (which does not). Always use self._state.setdefault(project_id, {})[key] = state to avoid KeyError when starting a single plugin independently.

Why: Bug discovered during test runs — enable_plugin failed with KeyError on self._state[project_id].
