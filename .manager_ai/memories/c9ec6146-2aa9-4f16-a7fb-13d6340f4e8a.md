Claude Code hook scripts (notify, TTS) live in `claude_resources/scripts/` and are copied to `.claude/scripts/` by `install_claude_resources_to()`. Hook commands in `settings.json` must use absolute paths via `$env:CLAUDE_PROJECT_DIR` (PowerShell syntax), NOT relative paths.

**Why absolute paths required:** Claude Code's CWD during hook execution is `backend/`, not the project root. Relative paths (`.claude/scripts/notify-hook.py`) resolve to `backend/.claude/scripts/` which doesn't exist. `$env:CLAUDE_PROJECT_DIR` is set by Claude Code during hook execution and always points to the project root.

**Why Python instead of PS1**: PowerShell scripts had `cygpath` dependency (`$(cygpath -w "$(pwd)")`) that only works in Cygwin/MSYS2. Standard Windows shells silently failed. Python `urllib` + `json` from stdlib works everywhere.

**Constraints**:
- Scripts must be stdlib-only — no pip deps (injected into arbitrary projects)
- Scripts must exit 0 always — hook failure must not break Claude Code
- Hook commands use `python -I "$env:CLAUDE_PROJECT_DIR\.claude\scripts\<name>.py"` (Windows backslash separators inside JSON)
- `install_claude_resources` copies files as-is — no platform-specific patching needed

**How to apply**: When adding new hooks, create stdlib-only Python scripts in `claude_resources/scripts/` and register in `claude_resources/settings.json` using absolute paths with `$env:CLAUDE_PROJECT_DIR`. Never use relative paths.
