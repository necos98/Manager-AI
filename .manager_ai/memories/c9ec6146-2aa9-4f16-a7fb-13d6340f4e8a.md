Claude Code hook scripts (notify, TTS) live in `claude_resources/scripts/` and are copied to `.claude/scripts/` per-project by the `install_claude_resources` endpoint. Hook commands in `settings.json` execute these scripts via `python -I .claude/scripts/<name>.py` (relative path from project root).

**Why Python instead of PS1**: PowerShell scripts had `cygpath` dependency (`$(cygpath -w "$(pwd)")`) that only works in Cygwin/MSYS2. Standard Windows shells silently failed, so hooks never executed. Python `urllib` + `json` from stdlib works everywhere without path translation tricks.

**Constraints**:
- Scripts must be stdlib-only — no pip deps (injected into arbitrary projects)
- Scripts must exit 0 always — hook failure must not break Claude Code
- Hook commands use relative paths from project root (Claude Code's CWD)
- `install_claude_resources` copies files as-is — no platform-specific patching needed with Python

**How to apply**: When adding new Claude Code hooks, create stdlib-only Python scripts in `claude_resources/scripts/` and register them in `claude_resources/settings.json` using `python -I .claude/scripts/<name>.py`.
