Each frontend feature (agents, pipelines, etc.) has a single api.ts and hooks.ts file. Export/import API functions and hooks should be added to these existing files, not created as separate api.export.ts files or a shared export/hooks.ts. This convention prevents PlanWriter from creating unnecessary separate files in future plans. The existing pattern is: features/{name}/api.ts and features/{name}/hooks.ts.
