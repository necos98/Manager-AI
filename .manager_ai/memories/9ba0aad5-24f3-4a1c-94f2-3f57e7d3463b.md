Import uses two-phase flow: POST /import/preview (parse + conflict detection) then POST /import/confirm (re-parse + apply). Both endpoints receive the same .json file as multipart/form-data (not stored server-side). Confirm endpoint also receives a 'conflicts' form field (JSON string mapping ID->skip/overwrite). Frontend uses uploadRequest helper for multipart. Pipeline import auto-creates referenced agents from inline step.agent data.
