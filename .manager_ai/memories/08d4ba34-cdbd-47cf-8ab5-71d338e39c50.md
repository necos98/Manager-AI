Default data seeding for agents and pipelines runs in TWO places:

1. **main.py lifespan** — at startup, after projects are loaded. Covers all existing projects.
2. **ProjectService.create()** — when a new project is created at runtime. After flush, calls AgentService.seed_defaults(project.id) then PipelineService.seed_defaults(project.id). Uses local imports to avoid circular deps.

Agent seed must run before pipeline seed because PipelineService.seed_defaults() queries agents to build default pipeline steps. Both seeds are idempotent: check for existing data, skip if present.
