Any code creating TerminalSessions in _sessions must clean up in this order: save_recording → stop_reader → pop → kill. The pipeline _execute() finally block and delete_project terminal loop were both fixed to match this canonical pattern from terminals.py. The _sessions dict leak was the root cause of terminal memory buildup during pipeline runs.
