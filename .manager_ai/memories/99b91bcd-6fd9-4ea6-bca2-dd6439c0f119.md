`CORS_ORIGINS=*` produces `["*"]` via `str.split(",")` (no special-casing). This is intentional: backward compat for non-credentialed setups, zero extra code. Without credentials, `allow_origins=["*"]` is valid CORS. No need to add if/else branching.
