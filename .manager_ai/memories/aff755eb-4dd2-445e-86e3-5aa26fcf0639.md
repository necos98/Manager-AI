Python 3.14's sqlite3 module returns tuples from fetchall() by default (not Row objects). Trying to call dict(row) on a tuple fails with "object is not iterable". Fix: set `conn.row_factory = sqlite3.Row` on the connection, then use `{k: r[k] for k in r.keys()}` to convert rows to dicts. The row_factory must be set before any queries.
