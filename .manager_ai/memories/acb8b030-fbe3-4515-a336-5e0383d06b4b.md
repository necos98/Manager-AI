IssueService.get_by_id() and TaskService methods scan all non-archived projects linearly (O(n)) calling load_issue per project. Fixed by maintaining a reverse index (issue_id → project_path) in MemoryStore, populated at init_project time and kept in sync via upsert/delete. The index avoids the scan — O(1) lookup instead. Archived exclusion handled by checking Project.archived_at after the index lookup. See issue 3ae77db5-4837-471a-8350-3522a63ee4bd.
