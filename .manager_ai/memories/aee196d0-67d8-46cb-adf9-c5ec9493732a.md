PipelineRun model has no `project_id` column. To query pipeline runs by project, JOIN through the `issues` table on `PipelineRun.issue_id == Issue.id` and filter by `Issue.project_id`. This avoids schema changes. Discovered during SpecReview of the active-by-issue optimization issue — the original spec incorrectly assumed `pipeline_run.project_id` existed.
