The "can't copy text in tabs" issue was caused by InlineEditField's onClick handler entering edit mode on every click — destroying text selections. The spec/plan/recap tabs (MarkdownViewer) already allow text selection. No CSS or layout blocking. Fix is in InlineEditField click logic + optional code block copy buttons in MarkdownViewer.
