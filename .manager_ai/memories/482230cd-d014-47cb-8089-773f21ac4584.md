In frontend/src/routes/queue.tsx, useSetAutoProcess() was placed after an if (isLoading) { return <Skeleton/> } early return. When isLoading transitions true→false, React sees N+1 hooks (the hook was skipped on mount). Fix: all hook calls (useState, useEffect, useQuery, useMutation) must be before any conditional return. This applies to ALL React components in the codebase — hooks after early returns will cause this same error pattern.
