Backend PipelineRunStatus enum: RUNNING, COMPLETED, FAILED (no PENDING, no CANCELLED — cancel sets status to FAILED). Backend PipelineStepRunStatus enum: PENDING, RUNNING, COMPLETED, FAILED. Both use UPPERCASE string values. Frontend types must match these exact strings.

Why: Frontend types mirror backend exactly. Wrong enum values break status display, conditional rendering, and API contracts. Cancel endpoint sets run to FAILED (not a separate CANCELLED status).
