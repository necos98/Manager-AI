After PK migration (Integer PK + uuid column), response schemas with from_attributes=True need id: str = Field(validation_alias="uuid") to read project.uuid instead of project.id. Config must include populate_by_name=True. Without this, model_validate fails because project.id (int) doesn't coerce to str. This pattern applies to ProjectResponse, DashboardIssue, DashboardProject. Routers that manually construct responses must change id=obj.id to id=obj.uuid.
