`h-full` (height:100%) in normal block flow resolves to 0 when parent has only `min-h-*` (no explicit height). TerminalPanel's ResizeObserver sees clientHeight===0 and xterm never opens. Fix: wrap in `flex flex-col` with inner `flex-1 min-h-0` to create proper height chain (matching TerminalGrid pattern). Affects any component embedding TerminalPanel outside a flex context.
