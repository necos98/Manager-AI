PipelineRunService.start() at pipeline_run_service.py:69-101 calls flush() (lines 77, 87) but never commit() before spawning _execute() via asyncio.create_task (line 99). _execute() opens a new session via session_factory() (line 238-239). New session can't see uncommitted PipelineRun + PipelineStepRun records → NotFoundError. Fix: insert await self.session.commit() at line 98 before create_task. This is a one-line fix, not a design issue — the pattern is fine, just missing the commit call.
