PipelineRunService.start() calls flush() (not commit()) before spawning _execute() as background task. _execute() creates a new session via session_factory and can't see uncommitted records → NotFoundError. Tests use PipelineRunService(db_session) without session_factory so _execute() reuses same session and never hits the race. Fix: commit() before create_task(). This pattern is likely present in other services that spawn background tasks — always commit before spawning a new session.
