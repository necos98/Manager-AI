The type `PendingQuestion` does not exist in the codebase. `usePendingQuestions()` returns `Question[]` from `@/shared/types` (same as `fetchPendingQuestions`). Any new component consuming pending question data should use `import type { Question } from "@/shared/types"`. The spec and initial plan draft referenced the non-existent `PendingQuestion` — fixed during PlanReview.
