When spawning background tasks via asyncio.create_task that open a new database session (via session_factory), the caller MUST commit() before create_task. If only flush() is used, the new session can't see the uncommitted records → NotFoundError. This affected PipelineRunService.start() — flush() at lines 77/87 but no commit before create_task at line 99. Fix: insert await self.session.commit() before asyncio.create_task. Tests didn't catch because they construct the service without session_factory, so _execute() reuses the same session where flushed data IS visible.
