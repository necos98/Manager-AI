Added "Hermes" tab in Settings page with executable CLI commands. Commands stored as JSON in setting `hermes_commands` (expandable). Each command shows name, description, command text, and a "Run" button. Click "Run" → creates a system-level PTY terminal via `POST /api/terminals/hermes` (no project/issue) → writes command into PTY → opens Dialog with TerminalPanel. Closing dialog kills the terminal. Backend has dedicated `create_hermes_terminal()` operation in terminal_operations.py following the manage-agent terminal pattern (project_id="", issue_id="", project_path auto-derived).
