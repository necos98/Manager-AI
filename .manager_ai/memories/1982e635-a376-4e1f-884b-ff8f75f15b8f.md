NewIssueDialog abandon-confirmation implemented via inline content swap inside DialogContent (not separate AlertDialog). showConfirm state controls form vs confirmation view. X button hidden during confirmation via showCloseButton={!showConfirm}. On successful submit, reset() runs before onOpenChange(false) so isDirty is clean. Escape during confirmation = abandon. Overlay click during confirmation = abandon (since already on confirm screen).
