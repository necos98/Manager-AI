When one service calls another service's method, use local imports inside the method body to avoid circular import issues at module load time.

Pattern:
```python
async def create(self, ...) -> Project:
    ...
    await self.session.flush()
    from app.services.agent_service import AgentService
    from app.services.pipeline_service import PipelineService
    await AgentService(self.session).seed_defaults(project.id)
    await PipelineService(self.session).seed_defaults(project.id)
    return project
```

**Why:** Service modules often form import chains (ProjectService → AgentService → app.models.agent → app.database, and app.models.project → app.database). Top-level imports of services within other services risk circular imports when the model layer connects them. Local imports defer resolution until after all modules are loaded.

**How to apply:** When adding cross-service calls, default to local imports. If tests prove no circular import exists, promote to top-level.
