_execute() changed from for-loop to while-loop driven by run.current_step_index. reject_step() (called from MCP tool session) updates current_step_index on PipelineRun + commits. _execute() session then calls session.refresh(run) after each step completion to pick up index changes. This is how regression works: the while loop naturally goes to whatever index is current.
