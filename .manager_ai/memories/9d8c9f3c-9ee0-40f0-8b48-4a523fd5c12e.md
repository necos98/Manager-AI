Implementation plan for start.py Windows orphan process fix extracts the re-exec logic into a _run_windows_reexec(cmd) helper function. This keeps _bootstrap_venv_and_reexec() readable and isolates the ctypes Job Object code. The helper uses a single try/except around the entire Job setup (CreateJobObjectW → SetInformationJobObject → Popen with CREATE_BREAKAWAY_FROM_JOB → AssignProcessToJobObject → wait), falling back to bare Popen.wait() on any failure. ctypes structs defined at module level under `if IS_WINDOWS:` guard. Matches existing desktop_icon.py ctypes pattern. PlanReviewer should cross-reference each constraint against the approach per prior spec-review finding.
