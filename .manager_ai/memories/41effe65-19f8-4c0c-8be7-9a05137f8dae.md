Pipeline step terminals now use real PTY via terminal_service.create(), NOT log terminals. Each step gets a PTY-backed terminal with mode="pty" (not mode="log"). terminal_id is a UUID string from TerminalService, no FK to terminal_commands. Previously used create_log() with pty=None — changed because user wanted PTY like RUN ISSUE. On CancelledError, terminal_service.kill(term_id) cleans up the PTY process.
