## Rule

Plugin MCP nel catalog devono aggiungere capability che Claude Code o Manager AI non hanno gia nativamente. Non aggiungere plugin che duplicano feature esistenti.

## Why

I plugin memory (`@modelcontextprotocol/server-memory`) e filesystem (`@modelcontextprotocol/server-filesystem`) sono stati rimossi perche ridondanti:
- **Memory**: Manager AI ha sistema memory integrato (tools `memory_create`, `memory_delete`, `memory_update`, `memory_search`, `memory_link`, `memory_unlink`) project-scoped.
- **Filesystem**: Claude Code ha accesso nativo al filesystem (Read, Write, Edit, Glob, Grep, Bash).

## How to apply

Prima di aggiungere un plugin al catalog, verificare che la capability offerta NON sia gia coperta da:
1. Tool nativi di Claude Code
2. Tool integrati di Manager AI (memory, issues, files, etc.)
3. Altri plugin gia presenti nel catalog

Esempio valido: `mysql` — Claude Code non puo interrogare MySQL nativamente.
