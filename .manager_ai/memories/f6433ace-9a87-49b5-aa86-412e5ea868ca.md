During plan review of issue 58e42e9a (show pipeline name), the plan referenced `runs[0]?.pipeline_name` for PipelineProgress but the component already derives `activeRun` via `find(r => r.status === "RUNNING")`. Plans should check for existing derived state in components to avoid suggesting redundant or slightly-off data access patterns. This applies especially when plans reference array-index access that could pick wrong item.
