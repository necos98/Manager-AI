_execute() uses session_factory to create its own DB session independent of MCP tool sessions. After _run_step() returns, _execute() does session.refresh(step_run) to detect REJECTED status. If MCP session hasn't committed, refresh returns stale data (still RUNNING), and _execute() overwrites to COMPLETED. Always ensure MCP session commits BEFORE signaling the background loop to wake up.
