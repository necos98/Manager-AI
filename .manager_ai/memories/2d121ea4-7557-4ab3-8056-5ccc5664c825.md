When a React component initializes local useState from a prop (e.g., `useState(() => Object.entries(variables))`), the state does NOT re-sync when the prop changes — the initializer runs only on first mount. If the prop changes due to a mutation/query refetch, the UI shows stale data. Fix: add `key={JSON.stringify(propValue)}` on the child component to force remount on prop change. Found during CodeReviewer pipeline step for the credentials.json Editor feature — EnvEditor showed old env vars after applying a preset.
