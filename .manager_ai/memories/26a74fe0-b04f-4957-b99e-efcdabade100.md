Commit 120c16d introduced a memory layer. list_issues() fallback path stores None as cached record value to force load_issue() disk reads. list_issues_full() returned all_records unfiltered, propagating None to callers expecting IssueRecord — crash on .relations access. Fix: filter None with listcomp. Pattern to watch for: any function returning _core.list_all() results should validate entries aren't None sentinels from a fallback path.
