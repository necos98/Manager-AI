ESLint in the frontend throws "Parsing error: Unexpected token" on ALL TypeScript files — missing or misconfigured `@typescript-eslint/parser`. This is pre-existing, not caused by new code. `npx tsc --noEmit` is the reliable type-check. Do NOT treat ESLint errors as regressions from new files.

Why: Pre-existing project issue. Avoid chasing false positives when adding new TS files. Fixing the ESLint config is a separate issue.
