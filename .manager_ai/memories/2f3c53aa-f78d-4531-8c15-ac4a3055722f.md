MCP pipeline CRUD tools (get/update/delete_pipeline, add/remove/reorder_steps) follow exact same pattern as Agent CRUD tools: async_session() → PipelineService(session) → try/except AppError → commit (or skip commit for read-only). reorder_steps must delegate to PipelineService (two-pass no_autoflush logic) — never reimplement.
