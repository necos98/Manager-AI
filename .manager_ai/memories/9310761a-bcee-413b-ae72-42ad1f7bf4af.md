CRITICAL BUG PATTERN (FIXED 2026-06-04): When converting _execute() from for-loop to while-loop, the run.current_step_index += 1 for normal step completion was omitted. The bug was documented during code review but the fix was never applied to code. Fixed in issue 57e5c8ea: added run.current_step_index += 1 after step_run.status = COMPLETED. Any future conversion of indexed loops to while-loop pattern must verify the increment variable advances on all paths (success, rejection, failure).
