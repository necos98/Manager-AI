Le notifiche Telegram vanno via Bot API diretta (httpx → api.telegram.org). Config: telegram.bot_token, telegram.chat_id, telegram.notifications_enabled in DB (Settings table), configurabili da UI Settings > Telegram. Il metodo TelegramService.configure() permette override dinamico dal DB. Fallback env vars da config.py se DB vuoto. Se TelegramService.is_configured() è False (token/chat_id vuoti o notifiche disabilitate), NotificationService (Hermes CLI subprocess) prende il controllo come fallback. Evita duplicati: TelegramNotifier manda la notifica solo se configurato, NotificationService salta se TelegramService è configurato.
