async SQLAlchemy commit expires all ORM attrs. Sync access to expired attr triggers lazy-load outside async context → MissingGreenlet. Fix: capture _response() (or any serialization) BEFORE db.commit(), save to variable, commit, return variable. Pattern found in agents.py (3 endpoints), also present in issue_relations.py and project_links.py (not yet fixed).
