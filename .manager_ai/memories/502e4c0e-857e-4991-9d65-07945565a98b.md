Specs sometimes propose new MCP tools for operations that extend existing flows (e.g. reject_step vs extending finished_pipeline_step). Prefer extending existing tools with optional params — fewer tools, backward compatible, simpler for agents. New tools only when the operation is fundamentally different from existing ones.
