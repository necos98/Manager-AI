In backend/app/mcp/server.py, all serialization helpers and tool functions format datetime fields with str() rather than .isoformat(). This affects _serialize_agent, _serialize_pipeline, and the _memory_to_dict/_file_to_dict helpers. Any new serialization in this file must use str() for consistency — the string format matters to MCP clients that may parse these values.
