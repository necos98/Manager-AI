force_finish_issue() in IssueService sets status to FINISHED directly (no transition validation), ignores all task completion checks, logs 'issue_force_finished' activity, fires ISSUE_COMPLETED hook with full context. Intentional escape hatch for manual override via GUI. MCP tool and REST endpoint both follow cancel_issue conventions.
