`break-words` (`overflow-wrap: break-word`) only breaks at soft wrap opportunities. When users paste text from Word, Google Docs, or other rich text editors, the content may contain non-breaking spaces (` `), zero-width characters, and long unbroken strings (URLs, paths) that bypass this property.

**Fix pattern**: Use `overflow-wrap-anywhere` (Tailwind v4) instead of `break-words` on `<textarea>` elements. Also add `resize-y` (prevents horizontal resize drag) and `overflow-x-hidden` (safety net).

**Affected component**: `frontend/src/shared/components/ui/textarea.tsx` — the shared Textarea component.

**Why**: This bug was previously fixed (issue 43aaf7dd, 2026-05-04) but regressed. The new fix at the shared component level prevents regression across all textarea usages.
