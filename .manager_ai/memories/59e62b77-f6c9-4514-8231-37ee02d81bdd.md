`list_issues()` stores `None` as the cached record in `_core.upsert()` for index-only entries (line 165). This means `list_issues_full()` can return a list containing `None`. Always filter: `[r for r in all_records if r is not None]`. The fallback path already does this correctly. Bug fixed in issue d52aee71.
