Full orchestrated pipeline flow successfully tested: run_pipeline(project_id, pipeline_id, issue_id, orchestrated=true) → WAITING_FOR_STEP → start_pipeline_step → Claude Code spawns in PTY, executes agent intent → agent calls finished_pipeline_step → advance_pipeline moves to next step → repeat until last step → pipeline COMPLETED.

Key gotcha: advance_pipeline MUST be called even after the last step completes. The pipeline stays in WAITING_FOR_STEP until advance_pipeline is explicitly invoked, which sets it to COMPLETED. This tripped us on the "Test Orchestrator Flow" pipeline — both steps completed via Claude Code and finished_pipeline_step, but pipeline remained WAITING_FOR_STEP until advance_pipeline was called.

Flow tested with: WriterAgent (writes file) → CheckerAgent (verifies file). ~3 min total. See issue 8aae24e0-b67f-459a-98be-213e6581e35b.
