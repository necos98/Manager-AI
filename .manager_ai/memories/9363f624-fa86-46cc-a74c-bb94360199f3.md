CredentialService encrypts credential fields with cryptography.fernet.Fernet. Key resolution order: (1) MANAGER_AI_SECRET_KEY env var, (2) data/secret.key file on disk, (3) auto-generated+persisted to data/secret.key on first startup (atomic write via temp+rename). Hard error if none available — no silent fallback. Key survives restarts via file persistence. Production deployments: set MANAGER_AI_SECRET_KEY env var explicitly.
