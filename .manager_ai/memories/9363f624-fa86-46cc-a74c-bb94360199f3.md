CredentialService encrypts credential fields with cryptography.fernet.Fernet. The key is read from MANAGER_AI_SECRET_KEY env var, and auto-generated (Fernet.generate_key()) if absent. Key lives only in env var — never persisted to DB or disk. If the key is lost, existing encrypted credentials become unreadable. Consider key backup for production use.
