Feature: show pipeline name + current step on issue detail page and Kanban cards.

Answered questions (Jun 4):
1. Kanban cards: use batch endpoint, not N+1. New endpoint `GET /api/pipeline-runs/active-by-issue?issue_ids=...` returning map of issue_id → {pipeline_name, current_step_index, steps_count}.
2. Detail page badge: show ONLY RUNNING pipeline status. Skip COMPLETED/FAILED.

Backend changes needed:
- PipelineRunResponse: add `pipeline_name: str`
- PipelineRunService.get_run() / get_runs_for_issue(): eager-load pipeline relationship, include pipeline.name
- New endpoint for batch active-run lookup (Kanban)
- Router exposes it at GET /api/pipeline-runs/active-by-issue

Frontend changes needed:
- PipelineRun TS interface: add pipeline_name
- IssueDetail header: render badge near StatusBadge when activeRun exists (pipeline name + "Step N/M: AgentName")
- IssuesPage: fetch active runs for all visible issues using batch endpoint
- KanbanCard: show compact badge when issue has RUNNING pipeline
