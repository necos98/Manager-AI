load_issue, load_memory, load_file have disk fallback: check MemoryStore first, if None → read from disk → upsert into MemoryStore → return. list_issues, list_memories, list_files fallback to reading index YAML from disk if MemoryStore index is empty, storing index entries only (None records) so subsequent load_* calls hit their disk fallback for full record bodies.

This ensures tests that seed files on disk (via _seed_issue etc.) still work without pre-loading MemoryStore. Write-side tests need flush_pending_writes() before checking disk state.
