config.py defines `_PROJECT_ROOT = Path(__file__).resolve().parent.parent.parent`. All paths to data/ should use `_PROJECT_ROOT / "data" / ...` (pathlib). Several places use `os.path.join("data", ...)` relative strings (main.py:337 secret key, main.py:395 WriteQueue). This inconsistency risks crashes when CWD != project root. New code should follow the pathlib pattern.
