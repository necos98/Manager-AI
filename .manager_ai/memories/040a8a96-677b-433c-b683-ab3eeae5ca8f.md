When a feature adds cross-project data (like project_links), an MCP tool must expose it to Claude Code AND CLAUDE.md must instruct Claude to use it. Without both, the LLM has no visibility. Pattern: add MCP tool in server.py using async_session + service, add description in default_settings.json, add usage instruction in CLAUDE.md. This applies to any future feature that affects how Claude understands or navigates the project ecosystem.
