PipelineRunService.start() creates PipelineRun+step_runs, flushes for IDs, then spawns _execute() via asyncio.create_task. _execute() creates a new session via session_factory. If the run isn't committed before create_task, _execute()'s new session can't see the run → NotFoundError. Fix: commit after creating step_runs, before create_task. Affects pipeline_run_service.py ~line 99. Similar pattern may apply to other create_task patterns in the codebase.
