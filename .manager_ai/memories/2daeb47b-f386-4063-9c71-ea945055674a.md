During plan review of the N+1 issue, the plan incorrectly said to remove the `fetchRelations` import from hooks-relations.ts. That import is still used by `useRelations()`, `useAddRelation()`, `useDeleteRelation()` in the same file — only `useBlockedIssueIds` was being rewritten. Pattern: when a plan says "remove import X" for a refactor that only touches one function in a file, verify X isn't imported by other functions in that file. Common in frontend files where multiple hooks share an import file.
