When updating services after PK migration, not all `session.get()` calls need changing. Calls where the ID comes from the DB (internal FK refs like PipelineRun.pipeline_id) keep using `session.get()` — the type change from String→Integer is transparent. Only API-facing lookups (where a UUID string comes from the request) need `session.get(Model, uuid_str)` → `select(Model).where(Model.uuid == uuid_str)`. This avoids unnecessary refactoring.
