Lifespan function in main.py decomposed into named helper functions (_startup_*, _shutdown_*) instead of one 148-line monolith. Error handling strategy: migration, project loading, and secret key ops are fail-fast (app doesn't start on failure). Seed defaults, status fixups, cleanup, catalog loading, resource install — wrapped in try/except, app continues. This matches the pattern already used in the codebase for non-critical startup ops vs the implicit criticality of DB-migration / project-loading.
