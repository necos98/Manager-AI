Issue DB model (issues table) is still queried in pipeline_run_service.py (joins PipelineRun→Issue, filters by project_id) and question_service.py (name lookups, joins), even though issue_service.py uses file-backed storage. Agent model is queried by name in agent_service.py (get_by_name, list_all, export). Project model is queried by name in project_service.py (list_all orders by lower(name), filters by archived_at).
