Agent model uses `intent` as the field name, NOT `system_prompt`. The `system_prompt` field was intentionally removed across the entire codebase. All API endpoints, MCP tools, schemas, and frontend forms must use `intent` exclusively.

**Why:** `system_prompt` was "zappato via" (intentionally removed) by the user. Only `intent` remains on the Agent model.

**How to apply:** When adding agent-related code, never introduce `system_prompt`. Use `intent` for MCP tool parameters, REST API schemas, frontend form fields, and TypeScript types. The Agent model field is `intent` (Text column).
