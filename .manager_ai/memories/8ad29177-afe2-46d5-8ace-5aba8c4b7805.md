TerminalService replaced threading.Lock with asyncio.Lock. All 10 lock-using methods became async. ~22 await keywords added across 5 caller files. asyncio.Lock is safe because all lock access is single-thread (event loop). Pre-existing race on _terminals dict reads (get, list_active, get_pty, active_count) left unchanged per non-goals. Asyncio-based concurrent test replaces threading.Thread in test_resize_concurrent_with_kill_does_not_crash. PTY.write() remains sync in event loop — accepted trade-off.
