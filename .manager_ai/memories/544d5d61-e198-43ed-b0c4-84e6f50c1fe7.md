main.py lifespan includes a startup cleanup block that queries RUNNING PipelineRuns and marks them FAILED with finished_at timestamp. Runs after the agent/pipeline seed block, before claude_resources install. Wrapped in try/except — non-fatal if it fails.

**Why:** Pipeline runs execute via in-memory asyncio tasks (PipelineTaskManager registry). Server restart loses all in-memory task references, leaving runs stuck in RUNNING status. Cleanup ensures they're marked FAILED so the UI shows correct status and new runs can be started for those issues.

**How to apply:** If adding new background task registries beyond PipelineTaskManager, add corresponding startup cleanup for their RUNNING/IN_PROGRESS states. Follow same pattern: async_session(), select RUNNING rows, mark FAILED, commit, log count.
