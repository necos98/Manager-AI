User decisions from brainstorming session for issue about adding export/import of agents and pipelines:

1. **UI + API** — both frontend buttons and backend REST endpoints
2. **Pipeline export includes agents** — pipeline JSON auto-contains its referenced agents' full data
3. **Import via .json file upload** — dedicated endpoint, not via file gallery system
4. **Conflict match by strict ID** — only same UUID triggers overwrite prompt
5. **Import shows preview** — user selects which items to import from a list

Architecture: two-phase import (upload → preview → confirm). Export is single-phase (request → download JSON).

Agents/pipelines are global (no project scope). Existing CRUD is complete — only export/import is missing. JSON must be added to allowed upload extensions if reusing file upload, but preferred approach is dedicated import endpoints that accept multipart file upload directly.
