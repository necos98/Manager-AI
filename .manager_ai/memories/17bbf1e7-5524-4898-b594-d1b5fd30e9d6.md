Audio files (ogg, mp3, wav, flac, m4a, aac) are transcribed using local openai-whisper base model. Transcription is async: upload returns immediately with extraction_status="pending", then asyncio.create_task fires _transcribe_async() in background. Server restarts are handled by recover_pending_transcriptions() called from main.py lifespan, which scans all projects' file indexes for audio files with pending status and re-triggers transcription.

Why: Avoid HTTP timeouts on large audio files. Fire-and-forget + startup recovery chosen over full job queue for simplicity — no new infrastructure needed. Model is lazy-loaded singleton (_get_whisper_model) so first transcription triggers ~1GB model download.
