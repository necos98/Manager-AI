PipelineRun model (pipeline_runs table) has no project_id column. To query pipeline runs by project, JOIN through the issues table on PipelineRun.issue_id == Issue.id and filter by Issue.project_id. This avoids DB migration. Used in the new GET /api/pipeline-runs/active-by-project?project_id=X endpoint.
