When spawning background tasks via asyncio.create_task that open new database sessions (session_factory), the creating session must commit() before create_task — not just flush(). Otherwise the new session can't see records the parent session created. Bug found in PipelineRunService.start() — one-line fix: insert await self.session.commit() before create_task. This pattern can recur anywhere flush() is followed by a background task with a fresh session.
