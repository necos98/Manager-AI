Bug pattern: pipeline_run_service._execute() creates WSL terminals via terminal_service.create() but never writes a `cd <posix_path>` into the PTY. terminal_service intentionally sets spawn_cwd=None for WSL (UNC paths rejected by CreateProcess), relying on callers to emit the cd. The router does this; the pipeline runner does not. Any code path that creates a terminal for WSL must emit `cd <posix_path>\r\n` immediately after create().
