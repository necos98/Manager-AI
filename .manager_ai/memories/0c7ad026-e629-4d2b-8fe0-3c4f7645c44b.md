Fixed command injection in terminal_service.py where shell_to_use (from Project.shell or MANAGER_AI_SHELL env var) flowed unvalidated into pty.spawn(). Applied 3-layer defense: (1) pydantic field_validator on shell in ProjectCreate/ProjectUpdate — rejects quotes, backticks, $, ;, |, &, newlines, carriage returns; (2) spawn-site regex guard at terminal_service.py:123 — _BAD_SHELL_CHARS re.compile(r"""['"`$;&|\n\r\\]""") catches all code paths including env var; (3) WSL path resolves wsl.exe via shutil.which() instead of trusting user-provided shell value — hard-fail if wsl.exe not on PATH.
