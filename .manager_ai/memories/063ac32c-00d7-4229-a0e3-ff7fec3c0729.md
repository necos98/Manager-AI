PipelineRunService.start() uses flush() not commit() before asyncio.create_task(self._execute()). _execute() opens new session via session_factory() which can't see uncommitted records → NotFoundError. Fix: add await self.session.commit() at pipeline_run_service.py:98 before create_task. This pattern (flush-then-spawn-background-task) should be flagged in future code reviews.
