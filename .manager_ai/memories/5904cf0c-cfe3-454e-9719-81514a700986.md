finished_pipeline_step MCP tool (server.py:1286-1303) now has a defensive fallback: when no RUNNING pipeline run is found for the issue, it checks if issue status is ACCEPTED. If so, it returns success with a warning instead of error. This prevents pipeline stalls when a previous step called accept_issue without calling finished_pipeline_step. The warning is logged to aid debugging. Added 2026-06-05 to fix issue 7b959db7.
