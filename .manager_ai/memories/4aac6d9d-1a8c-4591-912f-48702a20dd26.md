After PK migration, every uuid column on every model has default=new_uuid (from app.models._uuid import new_uuid). This auto-generates UUIDv4 on INSERT when no uuid is explicitly provided. Without this default, creating records without setting uuid fails NOT NULL constraint. Shared module app/models/_uuid.py provides the generator function — import in all model files. Do NOT use SQLAlchemy server_default (SQLite can't generate UUIDs).
