BUG PATTERN: In PipelineRunService.start(), commit() runs BEFORE asyncio.create_task() for _execute(). Any crash between them persists the run as RUNNING but _execute never spawns. Fix: create_task first, then commit. Add retry loop in _execute() for the ~100ms window where data isn't committed yet. Affected all pipeline starts before fix applied.
