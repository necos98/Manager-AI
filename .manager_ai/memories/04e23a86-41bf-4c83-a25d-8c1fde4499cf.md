The project exists in two directories on disk:
- `C:\Users\j.magarelli\Desktop\manager-ai\Manager-AI` — Python venv target, where `start.py` and the backend actually run
- `C:\Users\j.magarelli\Desktop\manager-ai\manager-ai-mod\Manager-AI` — working directory (where Claude Code session starts)

Both are git repos pointing to the same origin. The venv at `manager-ai\Manager-AI\venv` is configured with PYTHONPATH pointing to its own directory. Changes to backend code (models, services, etc.) MUST be applied to BOTH directories, or tests/alembic/runtime will use stale code from the venv-target directory.

**Why:** Unknown origin — likely a copy or re-clone at some point. The venv was set up against `manager-ai\Manager-AI` so all Python execution resolves there.

**How to apply:** Before running any Python command (pytest, alembic, start.py), check which directory the venv is in. Apply all backend file changes to both locations. Frontend changes only matter in the working directory.
