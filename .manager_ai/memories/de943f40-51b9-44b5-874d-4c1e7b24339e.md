Agent intents must never include issue lifecycle state transitions (accept_issue, complete_issue). Also: allowed_tools for pipeline agents must NOT include accept_issue or complete_issue — having the tool available creates the same risk even if the intent is clean. Lifecycle management lives exclusively in the /run-pipeline command. Defensive fallback exists in finished_pipeline_step MCP tool: when no RUNNING run found but issue is ACCEPTED, returns success instead of error.
