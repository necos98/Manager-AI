IssueResponse schema (file-backed in-memory store) has no pipeline run data. Pipeline runs are DB records with issue_id as a string column — no ORM relationship. Showing pipeline status on issues list requires either: (a) extending IssueResponse with optional pipeline_run field, (b) frontend-side separate fetch per issue, or (c) batch endpoint. Current recommendation: add pipeline_name to PipelineRunResponse schema + frontend handles fetching separately for list and detail views.
