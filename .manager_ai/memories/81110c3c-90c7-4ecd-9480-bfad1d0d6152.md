When using a decorator under @mcp.tool(), FastMCP uses inspect.signature() to discover tool parameters. Using functools.wraps sets __wrapped__ which inspect follows, exposing internal params (like session) to MCP clients. Fix: don't use functools.wraps — manually copy __name__, __qualname__, __doc__, __annotations__, and set __signature__ to a modified signature that excludes injected params.
