When registering plugin tools on FastMCP via `_make_proxy_function`, the proxy function must have an explicit `__signature__` built from `tool.inputSchema` properties. Using bare `**kwargs` causes FastMCP to generate a Pydantic model with a single `kwargs: str` parameter, which rejects the actual named arguments from Claude. Fix: use `inspect.Signature` with `inspect.Parameter` objects derived from `inputSchema["properties"]` (required → no default, optional → default None), assign to `proxy.__signature__`. This applies to ALL plugins generically, not just MySQL.
