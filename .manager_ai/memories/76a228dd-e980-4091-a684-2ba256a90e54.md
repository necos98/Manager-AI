When an issue is in the queue, a badge "In Queue (#pos)" appears in the issue detail page header (near StatusBadge and Pipeline badge). Uses the same useQueuePosition hook already used by IssueActions. Badge shows amber colors (bg-amber-50 text-amber-700 border-amber-200) and is visible for ALL issue statuses (not just New/Accepted), because queue membership is tracked independently via QueueEntry table.
