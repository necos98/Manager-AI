Per sostituire confirm() nativo del browser con Radix Dialog: (1) stato confirmKillId: string | null con useState, (2) handleKill(terminalId) setta confirmKillId invece di chiamare confirm(), (3) doKill() chiama mutate con onSuccess che resetta lo stato, (4) Dialog JSX con DialogHeader (titolo + descrizione), DialogFooter (Cancel outline + Terminate destructive). Stesso pattern dei delete confirmation dialog in issue-detail.tsx e queue.tsx. Esempio in frontend/src/routes/terminals.tsx.
