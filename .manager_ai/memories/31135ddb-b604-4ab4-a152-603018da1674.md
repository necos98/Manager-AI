When adding new operations for an existing domain (e.g. export/import for agents or pipelines), add API functions to the existing `api.ts` file and hooks to the existing `hooks.ts` file. Do NOT create new per-feature files like `api.export.ts` or `export/hooks.ts`. Each domain (agents, pipelines) has exactly one `api.ts` and one `hooks.ts`. This was discovered during PlanReview of export/import feature — the initial plan proposed new files but the codebase convention uses existing ones.
