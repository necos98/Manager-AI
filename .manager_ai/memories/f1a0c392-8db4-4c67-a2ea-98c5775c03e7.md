Storage layer uses RAM-first architecture. MemoryStore (nested dict) is the source of truth. Writes go: caller → MemoryStore.upsert → WriteQueue.enqueue → return (non-blocking). BackgroundWriter async task drains queue to disk in batches of 10, idle sleep 500ms. Disk is output-only; never read during runtime except at startup and via fallback for backward compat.

Three new modules: memory_store_core.py (MemoryStore singleton), write_queue.py (SQLite pending_writes table with dedup), background_writer.py (async worker + flush_all_pending helper).

WriteQueue is injected into store modules via inject_write_queue() at startup. Tests use conftest.py to inject and flush on teardown.

Killed: ReadCache, ManagerAiWatcher, prewarm_project_cache, watchfiles dependency.
