Projects can be favorited via `favorited_at` (nullable datetime) on the `projects` table. Pattern: use nullable timestamp over boolean when a toggle needs sort ordering — `ORDER BY favorited_at IS NOT NULL DESC, favorited_at DESC` puts favorites first (most recent first), non-favorites alphabetical. Null = not favorited, non-null = favorited at that instant.

Toggle done via existing `PUT /api/projects/{id}` with `{"favorited_at": "<ISO timestamp>" | null}` — no dedicated endpoint needed.

Frontend: `ProjectSidebarItem` component (extracted from inline `.map()` to allow `useUpdateProject` hook per row). Star icon from lucide-react, `SidebarMenuAction` with `showOnHover`, `text-yellow-400` + `fill="currentColor"` when active, outline when not. Optimistic update via React Query `useUpdateProject` mutation.

Why: User wanted favorites/pinned projects in sidebar. Timestamp chosen over boolean for free ordering. SidebarMenuAction reused instead of custom button.
