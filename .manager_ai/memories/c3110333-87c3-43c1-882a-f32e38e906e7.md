QUEUED fully removed from IssueStatus enum (2026-06-10). `add_to_queue()` emits `queue_entry_created`, `remove_from_queue()` emits `queue_entry_removed` — no more synthetic `issue_status_changed → Queued` events. IssueQueueService.notify() listens for `queue_entry_created` instead of `new_status == "Queued"`. Frontend invalidates queue cache on `queue_entry_created`/`queue_entry_removed` event types. No issue status change when adding/removing from queue — QueueEntry table is sole authority.
