When registering proxy functions via mcp.add_tool(), the function MUST use un-annotated **kwargs. FastMCP's Tool.from_function() calls issubclass(param.annotation, Context) on every parameter — non-class annotations like `Any`, `Union`, or `Optional` will raise TypeError: issubclass() arg 1 must be a class.

Why: Discovered during MCP plugin system implementation. Generated proxy functions with typed **kwargs failed registration. Fix: remove all type annotations from **kwargs in proxy functions.
