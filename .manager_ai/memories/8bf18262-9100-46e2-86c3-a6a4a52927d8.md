Plan for issue c4efe87f. 3-layer defense: pydantic validator on shell field (ProjectCreate/ProjectUpdate), spawn-site char-class regex guard in terminal_service.py:118, WSL path resolves wsl.exe via shutil.which() instead of trusting user shell. Key architectural decision: reject-list char check (not allowlist of known shells) because valid shells are unbounded (any valid exe path), while dangerous chars are finite and stable. Hard-fail on shutil.which() returning None rather than silent fallback — fail-fast is safer for security fixes.
