Six sites in terminals.py and projects.py pass URLs (host_ip, port) into pty.write() f-strings without shlex.quote(). Three cases use bash double quotes which still expand $, backticks, backslashes. Three use no quoting at all. Fix: add quote_url_for_shell() helper to wsl_support.py — wraps with shlex.quote() for bash/WSL and double-quotes for cmd.exe. Identified in issue 1141c558, pipeline run 007f4565.
