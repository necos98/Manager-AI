The PipelineService.add_step() method accepts an order_index parameter but never uses it — it always auto-assigns max+1 regardless of what's passed. This means MCP tools calling add_step should accept order_index for API consistency but the value is effectively ignored server-side. Relevant for anyone adding pipeline step tools or modifying the service. Source: pipeline_service.py lines 78-99.
