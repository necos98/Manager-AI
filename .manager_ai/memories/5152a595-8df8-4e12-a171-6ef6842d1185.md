PipelineRunService._execute() creates terminals via terminal_service.create() without passing shell or wsl_distro. This causes pipeline terminals to always default to CMD.exe regardless of project's shell setting. REST API endpoints (terminals router) correctly fetch and pass these values. Fix: read Project.shell and Project.wsl_distro before creating pipeline terminal and pass them to terminal_service.create().
