`DEFAULT_AGENTS` in `agent_service.py` includes `terminal_command` for each agent defining what task to pass to `claude -p`. This field lives in the Python data structure, NOT on the Agent SQLAlchemy model — no migration needed.

`PipelineService.seed_defaults()` builds a lookup dict `cmd_by_name` from `DEFAULT_AGENTS` and sets each `PipelineStep.terminal_command` accordingly. For custom agents created after seeding, `terminal_command` defaults to empty string — the PipelineStep must be manually updated via the API/frontend.

**Why:** All default pipeline steps had `terminal_command=""`, so Claude was launched with an empty task and didn't know what to do. Adding commands to DEFAULT_AGENTS and wiring them through seed_defaults() fixes this without a DB migration.

**How to apply:** When adding new default agents, always include a `terminal_command`. When modifying an existing default agent's role, update its `terminal_command` to match.
