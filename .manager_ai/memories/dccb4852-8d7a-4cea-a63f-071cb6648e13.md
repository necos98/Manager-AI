`from app.services.issue_queue_service import issue_queue_service_ref` at module level creates a local binding of the value at import time (None). Later `global issue_queue_service_ref; issue_queue_service_ref = self` in __init__ only modifies the source module's attribute — the importing module's local binding stays None forever.

Fix: import inside each function body (lazy import), so the module attribute is re-evaluated each call. Same pattern as shared_tools.py: `def func(): from app.services.issue_queue_service import issue_queue_service_ref; if issue_queue_service_ref is None: raise 503; ...`.

This caused the 503 "Queue service not initialized" bug in queue.py when lifespan startup failed before IssueQueueService() was created (due to schema mismatch), and even after fixing the schema, the module-level import still bound None permanently.
