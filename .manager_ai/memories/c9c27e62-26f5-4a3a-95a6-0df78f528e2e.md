PipelineRunService.start() now calls create_task/start_task BEFORE commit(). This eliminates crash window where DB had RUNNING but background task never spawned. _execute() has a retry loop (50×, 100ms) for the timing window where it runs before commit finishes. This pattern supersedes the old commit()-before-create_task approach (memories 063ac32c, 09ac88a3 now marked SUPERSEDED).
