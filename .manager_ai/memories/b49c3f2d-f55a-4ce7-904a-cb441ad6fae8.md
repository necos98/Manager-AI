When adding TerminalSession cleanup anywhere in new code, the order must be: _save_recording → _stop_reader → _sessions.pop → kill. This matches the canonical _teardown_terminal() pattern in terminals.py:35-52. Any deviation leaks TerminalSession objects in the _sessions dict. Applied in pipeline_run_service.py _execute() finally block and projects.py delete_project terminal loop.
