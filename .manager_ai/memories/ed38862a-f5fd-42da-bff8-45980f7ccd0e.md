`allow_origins=["*"]` + `allow_credentials=True` is rejected by browsers per CORS spec. Fix: configure specific origins via `Settings.cors_origins` (comma-separated string in config.py, split at middleware registration). Defaults to `http://localhost:5173,http://127.0.0.1:5173`. Also update `.env.example` with `# CORS_ORIGINS=`.
