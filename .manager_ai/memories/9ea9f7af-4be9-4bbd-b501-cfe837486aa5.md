The health panel checks for MCP server registration by reading two config files: project-level `.mcp.json` and global `~/.claude.json`. Each check looks for a specific server name key under `mcpServers`. Currently two checks exist: `_check_mcp` (for "ManagerAi") and `_check_playwright_mcp` (for "Playwright"). They are structurally identical — if a third MCP server is added, refactor to `_check_mcp_server(project, server_name)` to avoid further duplication. The global config also supports project-scoped entries under a `projects` key.
