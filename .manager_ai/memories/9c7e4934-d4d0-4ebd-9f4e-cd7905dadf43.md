The standard text reference format for project files is `@.manager_ai/resources/{file.stored_name}` (NOT `original_name`). This format is used in three places:
- Terminal panel file selection (`terminal-panel.tsx:81`)
- Global image paste hook (`use-global-image-paste.ts:51`)
- New Issue dialog Browse Files button (`new-issue-dialog.tsx`)

`stored_name` is `{uuid}.{ext}` — the actual file on disk under `.manager_ai/resources/`. Claude resolves `@` paths when reading issue descriptions and terminal input.

**Why:** This convention emerged from the terminal where Claude needs a real filesystem path. It stuck because Claude already understands `@`-prefixed paths as project file references. New features that reference files in text should use this same format.
