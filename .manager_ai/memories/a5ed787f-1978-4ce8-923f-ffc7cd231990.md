The venv at `C:\Users\j.magarelli\Desktop\manager-ai\Manager-AI\venv` has Python importing from `C:\Users\j.magarelli\Desktop\manager-ai\Manager-AI\backend`, NOT from the working directory `C:\Users\j.magarelli\Desktop\manager-ai\manager-ai-mod\Manager-AI\backend`. When editing backend Python files, changes must be applied to BOTH locations or they won't take effect at runtime/tests.

Why: The venv was set up from the `Manager-AI` directory (likely via `pip install -e .` or similar). Python's import resolution finds that path first. The `manager-ai-mod` directory is the git working copy. Tests and `start.py` use the venv and import from `Manager-AI`.

How to apply: After editing any backend `.py` file in `manager-ai-mod/Manager-AI/backend/`, check if a corresponding file exists in `Manager-AI/backend/` and apply the same changes there. Use `python -c "import app.services.<module> as m; print(m.__file__)"` to verify which copy Python loads. Frontend changes are unaffected (only in manager-ai-mod).
