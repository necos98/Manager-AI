_execute() background task had no except Exception handler. Unhandled exceptions (like MultipleResultsFound) silently escaped — pipeline stayed RUNNING in DB with no FAILED event. Fix: add except Exception handler that sets run FAILED + emits pipeline_completed event. This pattern applies to ALL background asyncio.create_task pipelines in pipeline_run_service.py.
