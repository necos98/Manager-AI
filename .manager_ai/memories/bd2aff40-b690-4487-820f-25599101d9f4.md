Manager AI frontend uses a double sidebar layout with independent `SidebarProvider` components from shadcn/ui.

**How it works:**
- Each sidebar has its OWN `SidebarProvider` for independent collapse state
- ProjectSidebar: `style={{ "--sidebar-width": "220px" }}` with `collapsible="icon"` + `SidebarRail`
- AppSidebar: `style={{ "--sidebar-width": "260px" }}` with `collapsible="icon"` + `SidebarRail`
- Each provider creates its own React context + CSS variable scope, so widths and collapse states don't conflict
- Independent SidebarProviders create cumulative gaps only when both are expanded: 220px + 260px = 480px total
- When one collapses, it shrinks to 3rem (--sidebar-width-icon), freeing space for content
- When `activeProject` is null, AppSidebar returns null → no inner gap created → single-column layout

**Why:** User wanted persistent project visibility without a dropdown. Double sidebar pattern (Slack/Discord/Linear style) with independent collapse per sidebar.

**localStorage keys:** `sidebar-project`, `sidebar-app` (boolean, persists across sessions).

**Mobile:** Each Sidebar has its own mobile Sheet via shadcn. A native Sheet trigger (hamburger icon) in the mobile header opens ProjectSidebar. SidebarTrigger in header doesn't work with separate providers — use native Sheet instead.

**Collapse handle:** SidebarRail (thin vertical strip on the edge) + Ctrl/Cmd+B shortcut. Tooltips via SidebarMenuButton `tooltip` prop show when collapsed.
