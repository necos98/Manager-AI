Manager AI frontend uses a double sidebar layout with nested `SidebarProvider` components from shadcn/ui.

**How it works:**
- Outer `SidebarProvider` with `style={{ "--sidebar-width": "220px" }}` wraps the ProjectSidebar (all projects + global nav)
- Inner (default-width) `SidebarProvider` wraps the conditional AppSidebar (project-scoped nav only)
- Each SidebarProvider creates its own React context + CSS variable scope, so widths don't conflict
- Nested SidebarProviders create cumulative gaps: 220px + 260px = 480px total offset for main content when both visible
- When `activeProject` is null, AppSidebar returns null → no inner gap created → two-column layout

**Why:** User wanted persistent project visibility without a dropdown. Double sidebar pattern (Slack/Discord/Linear style) separates concerns: left = what project am I in, right = what page within that project.

**How to apply:** Any future sidebar changes must respect the nested provider boundary. Don't assume single SidebarContext. The outer sidebar's trigger would need its own placement (currently no desktop trigger for outer sidebar). Mobile: only inner sidebar has a trigger button.
