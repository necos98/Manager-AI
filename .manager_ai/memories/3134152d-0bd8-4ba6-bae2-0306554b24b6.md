Force Finish button allows marking any issue as Finished regardless of status, task completion, or other constraints. Implemented as force_finish_issue() in IssueService with no status validation (unlike complete_issue). Fires ISSUE_COMPLETED hook. Has dedicated REST endpoint POST /{issue_id}/force-finish, MCP tool force_finish_issue, and frontend button with confirm dialog (destructive variant, optional recap). The issue_name metadata uses description fallback (rec.name or rec.description[:50] or "Untitled"). Staged/committed as part of issue #5c86fb70.
