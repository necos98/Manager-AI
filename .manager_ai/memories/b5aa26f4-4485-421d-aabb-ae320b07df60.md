Export/Import Agents & Pipelines uses two-phase import: (1) POST /api/import detects conflicts by name (read-only), (2) POST /api/import/resolve commits with overwrite choices. Scope param ("agents"/"pipelines"/"both") lets Agents page only import agents and Pipelines page only import pipelines. Pipeline steps embed full agent data inline in export JSON for self-contained files. Import auto-creates referenced agents for pipelines when they don't exist. Within-file duplicates detected by name (first wins). New UUIDs generated for all imported entities (file IDs not preserved). Overwritten entities retain their existing IDs.
