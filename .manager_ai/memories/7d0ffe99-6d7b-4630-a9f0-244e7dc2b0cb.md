In async SQLAlchemy, await db.commit() expires all ORM object attributes. Any synchronous access to an expired attribute triggers lazy-load, which requires an async greenlet context. Always capture _response() / serialize ORM data BEFORE calling commit. Pattern: resp = _response(obj); await db.commit(); return resp. Affected files: agents.py (fixed), issue_relations.py line 31-32 (has same pattern), project_links.py line 35-36 (has same pattern).
