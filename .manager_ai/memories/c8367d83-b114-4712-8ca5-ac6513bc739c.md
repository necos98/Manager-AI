Frontend `useBlockedIssueIds` (hooks-relations.ts:35-51) uses `useQueries` to fire N parallel `fetchRelations(i.id)` calls — one per issue. Each hits `GET /api/issues/{issue_id}/relations`. On backend, each call scans ALL projects' ALL issues in MemoryStore. Fix: add batch endpoint + replace useQueries with single query.
