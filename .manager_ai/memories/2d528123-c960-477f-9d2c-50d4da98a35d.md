Export uses backend endpoints GET /agents/export, GET /agents/export/{id}, GET /pipelines/export, GET /pipelines/export/{id}. Frontend calls via fetch → res.blob() → downloadBlob() (hidden anchor click, no Save-As dialog). No selective export — only "all" or "single". No feedback after download. Pipeline export does include related agents in step data already. Agent single export filename is "agent-export.json" (generic). User wants: (1) checkbox selection per section, (2) pipeline export includes its agents, (3) native Save-As dialog.
