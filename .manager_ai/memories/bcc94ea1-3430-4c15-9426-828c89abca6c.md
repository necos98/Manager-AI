Quick Create Issue implemented as a separate QuickCreateIssueDialog component (not a mode of NewIssueDialog) to keep the full-featured dialog clean. Only description + priority fields. No abandon-confirmation — quick create is fast enough that confirmation is unnecessary friction. Dialog state managed at ProjectSidebar level via quickCreateProjectId state, not inline in each sidebar item.
