The ask_user_question MCP tool inserts into `questions` DB table which has a ForeignKey on `issues.id`, but issues are file-backed (YAML+markdown in .manager_ai/issues/). This means ANY call to ask_user_question for a file-backed issue fails with `sqlite3.IntegrityError FOREIGN KEY constraint failed`. This blocks pipeline agents from asking the user questions during execution. Known bug documented in memories 8c9970aa and 6d8e5fda. Workaround: use send_notification to ask the user, or fix by removing the FK constraint from questions.issue_id.
