Project model now has url: Mapped[str | None] column (String(2000), nullable). Used by Playwright MCP tools to determine the web app base URL. Only projects with a URL configured can use Playwright browser testing. The field is exposed in all project schemas (Create/Update/Response) and in frontend types.
