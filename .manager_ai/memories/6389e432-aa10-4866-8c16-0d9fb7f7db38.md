The root-level index files `issues.yaml`, `memories.yaml`, and `files.yaml` under `.manager_ai/` are auto-generated aggregates rebuilt from individual directory files on every server startup (in `ManagerAiWatcher.start_project()`). They are excluded from git tracking via `.manager_ai/.gitignore`.

**Why:** Git operations (merge conflicts, partial pulls) can corrupt these index files, losing track of issues/memories/files even though the individual source files are intact. The individual files in `issues/<id>/`, `memories/<id>.md`, and `files/<id>.txt` are the single source of truth.

**Rule:** Never edit these index YAML files directly. Never commit them to git. If you need to add/update an entry, write the individual file in the appropriate subdirectory — the watcher or next startup will rebuild the index. If the index seems stale, restart the server to force a rebuild.
