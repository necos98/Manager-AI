Unlike service.get() and service.resize() (which raise KeyError for missing terminals), service.kill() uses self._terminals.pop(terminal_id, None) and returns early if None. This means kill() is always safe to call on any terminal_id — it silently handles already-cleaned-up terminals. Tests should expect no-op, not KeyError.
