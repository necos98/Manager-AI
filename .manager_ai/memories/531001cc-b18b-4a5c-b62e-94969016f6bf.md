`useSpeechRecognition` hook and `SpeechModal` component are generic (no feature-specific dependencies) and live in `shared/`:
- `frontend/src/shared/hooks/use-speech-recognition.ts` — wraps browser SpeechRecognition API
- `frontend/src/shared/components/speech-modal.tsx` — modal UI with mic toggle, transcript display, editable textarea

Any feature needing voice input (terminal, issues, etc.) should import from these shared paths.
