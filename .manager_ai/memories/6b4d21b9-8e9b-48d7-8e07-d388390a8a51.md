Manage-agent terminals (AGENTS "Start Conversation") are created with project_id="" and issue_id="". They are section-internal, not project terminals. The global `/terminals` listing must filter them out: `[t for t in terminals if not (t["project_id"] == "" and t["issue_id"] == "")]`. Add this filter in `list_terminals` endpoint. The dedicated `/terminals/manage-agent` endpoint returns them via `list_active(project_id="", issue_id="")`.
