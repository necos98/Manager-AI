Frontend features follow the pattern established by the `terminals` feature: each feature lives under `frontend/src/features/<name>/` with two files — `api.ts` (REST client functions using `apiGet/apiPost/apiPut/apiDelete` from `@/shared/api/client`) and `hooks.ts` (React Query wrappers using `@tanstack/react-query` with query key factories, `useQuery`/`useMutation`, `invalidateQueries` on success, and `toast.error` from sonner on mutation error). Feature directories should match backend router separation (e.g. separate `agents/`, `pipelines/`, `pipeline-runs/` since backend has separate routers). Shared types go in `frontend/src/shared/types/index.ts`.

Why: Consistent pattern used across all features. Following ensures new code integrates with existing React Query cache invalidation and error handling conventions.
