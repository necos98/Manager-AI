The refactored TerminalActionBar component's "Close Terminal" and "Close All" buttons call `onRequestClose` which triggers `setShowCloseConfirm(true)`. The actual kill-terminals logic (`closeAll`) lives in TerminalDialogs, called from the dialog's "Confirm" button. This boundary split is important to get right: TerminalActionBar triggers dialog open, TerminalDialogs handles confirmation and actual kill. The `closeAll` function must NOT be passed to TerminalActionBar.
