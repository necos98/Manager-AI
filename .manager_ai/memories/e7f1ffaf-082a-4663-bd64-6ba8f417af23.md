`_startup_seed_defaults` preserves the original per-call rollback pattern: AgentService.seed_defaults() and PipelineService.seed_defaults() each have their own try/except/rollback block within a single `async with async_session()` context. PipelineService depends on agents existing (it queries agents to build default pipeline steps), but the rollback isolation ensures one can fail without side-effecting the other's session state. This is intentional — not consolidated into a single transaction.
