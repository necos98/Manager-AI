Avoid importing between `frontend/src/features/agents/hooks.ts` and `frontend/src/features/pipelines/hooks.ts` — they are sibling feature modules with no existing cross-imports. Adding `import { pipelineKeys } from "@/features/pipelines/hooks"` in one AND `import { agentKeys } from "@/features/agents/hooks"` in the other creates a circular dependency. Use raw query key arrays `["agents"]` / `["pipelines"]` instead — React Query fuzzy matching works identically (`exact: false` default matches both list and detail keys). This is the same approach used in `event-context.tsx`.
