Decision from issue 3c933e0b: convert ALL tables to auto-increment integer PKs with a separate String(36) uuid column for external references. Rationale: simpler joins, better index perf, smaller storage, user preference. Scope: schema/models only — API continues to expose UUIDs for backward compat. Affects 19 UUID-PK tables + 5 integer-PK tables (add uuid column to those).
