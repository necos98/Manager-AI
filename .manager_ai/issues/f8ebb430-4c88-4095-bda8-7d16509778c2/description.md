## Layout mobile responsive

**Problema:** App non fruibile su mobile. Sidebar non collassabile, Kanban non responsive.

**Obiettivo:** Supporto base mobile.

**Cosa fare:**
1. Sidebar collassabile a overlay su mobile
2. Kanban diventa lista verticale con filtri ad accordion
3. Bottom navigation invece di doppia sidebar
4. Issue detail con tab verticali invece di resizable panels
