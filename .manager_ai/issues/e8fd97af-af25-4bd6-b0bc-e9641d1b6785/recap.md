Implemented pipeline event rules system for rejection recovery. New PipelineEventRule model (SQLAlchemy, DB-backed) with UniqueConstraint on (pipeline_id, event_type, source_step_id). CRUD via PipelineService, REST API at /api/pipelines/{id}/event-rules, and MCP tools (add/remove/list). Modified finished_pipeline_step to auto-resolve target_step_index from event rules when omitted — agents no longer need to know pipeline topology. Export/Import includes event_rules with step ID remapping. Frontend UI in PipelinesTab with event rule add/remove per step. Event_type is string column — future event types need no schema changes. Tests cover CRUD, validation, rejection target resolution.
