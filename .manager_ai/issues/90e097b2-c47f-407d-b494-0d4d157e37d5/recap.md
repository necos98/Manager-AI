Fixed Windows PTY exit race condition in pipeline_run_service.py:_run_step(). The `exit` command was written as a separate `pty.write()` call after the `claude` command, creating a race where `cmd.exe` could process `exit` before `claude.exe` finished. Merged exit into the same write using `&` chaining (`command & exit\r\n`), matching the semantics of bash `;` on Linux. 1 insertion, 2 deletions.
