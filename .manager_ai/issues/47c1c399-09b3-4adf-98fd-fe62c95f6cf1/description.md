## Cmd+K global search e keyboard shortcuts

**Problema:** Nessuna command palette o ricerca globale. Unica shortcut: Cmd+Enter per submit.

**Obiettivo:** Command palette stile Linear/VSCode accessibile via Cmd+K.

**Cosa fare:**
1. Cmd+K apre command palette globale
2. Ricerca full-text su issue (tutti i progetti), progetti, pagine app
3. Shortcut: n nuova issue, g i/d navigazione, / search focus, ? help
4. Risultati raggruppati per categoria
5. Navigazione con frecce + Enter

**File:** Nuovo `command-palette.tsx`, `use-keyboard-shortcuts.ts`
