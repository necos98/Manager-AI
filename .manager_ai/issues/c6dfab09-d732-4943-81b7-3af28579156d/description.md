Creare un sistema di logging robusto per il backend di Manager AI. Gli errori del backend devono essere incanalati in una cartella "backend/logs" e deve essere creato un file di log per ogni errore riscontrato. Il sistema deve gestire: eccezioni non catturate, errori HTTP, errori di validazione, errori di database, errori dei plugin MCP, errori del terminal service, e qualsiasi altra eccezione sollevata dal backend. Ogni file di log deve contenere timestamp, tipo di errore, stack trace completo, contesto della richiesta (se applicabile), e metadati utili al debugging.
