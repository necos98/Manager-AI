## Dashboard con metriche e grafici

**Problema:** Dashboard attuale mostra solo griglia di progetti con issue attive. Nessuna metrica.

**Obiettivo:** Arricchire dashboard con KPI e visualizzazioni.

**Cosa fare:**
1. Metriche: issue completate/7gg, tempo medio completamento, pipeline completate
2. Grafico a barre stato issue per progetto
3. Activity feed globale (ultime 10 attivita)
4. Widget In esecuzione ora con pulse indicator
5. Filtro temporale (7gg, 30gg, 90gg)
