Nella sezione Settings del Manager AI (Desktop), quando si apre un terminale (ad esempio per configurare Hermes o fare altre operazioni), si verifica un errore nella console del browser/devtools. Investigare e fixare il problema.

Dettagli:
- Dove: Settings → apertura terminale
- Errore: visibile nella console devtools
- Impatto: potrebbe impedire il corretto funzionamento del terminale nella settings
