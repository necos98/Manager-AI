## Filtri Kanban avanzati

**Problema:** Filtri in una riga di select sopra la board. Su schermi stretti si rompono.

**Obiettivo:** Pannello filtri piu potente e flessibile.

**Cosa fare:**
1. Pannello filtri collassabile
2. Filtro full-text rapido nell header
3. Filtro per agente/assegnatario
4. Salvataggio preferiti di filtro per progetto
