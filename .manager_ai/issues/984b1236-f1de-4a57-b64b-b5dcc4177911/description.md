## Breadcrumb navigation

**Problema:** Navigando in profondita non c'e indicazione di posizione nella gerarchia.

**Obiettivo:** Breadcrumb navigabili nell'header di ogni pagina.

**Cosa fare:**
1. Breadcrumb dinamico basato sulla route attuale
2. Formato: Projects > NomeProgetto > Issues > TitoloIssue
3. Ogni segmento cliccabile per risalire
4. Troncare segmenti intermedi su schermi stretti
